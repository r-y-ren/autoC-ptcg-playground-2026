# T2 受控坐标表（四级可控性）

| 状态坐标 | 可控性四级 | 说明 |
|---|---|---|
| 出牌选项索引 | 可控 | select.option 索引直接决定（唯一动作通道） |
| 牌组构成 | 可控 | deck 阶段 60 卡自定（当前=引擎默认组） |
| 场面局势/奖赏进度 | 可影响 | 双方共推（策略主战场） |
| 对手手牌构成 | 可观测不可推 | 仅 handCount+弃牌区可推（观测器对象） |
| 洗牌/掷币 | 不可控随机 | C 层无种子入口，全局方差 |
| 先后手 | 不可控随机 | BO 轮间自动交替（cabt.py:215）部分对冲 |
